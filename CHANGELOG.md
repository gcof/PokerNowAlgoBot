# Changelog

## 0.8.0 — 2026-10-23

First portable repository release, prepared from the private 0.7.x prototype.

- Removed embedded player identities, nicknames, private table URLs and machine-specific paths.
- Detect any local seated account; support both PokerNow HTTPS hostnames.
- Handle table transfers, opt-in resume and cross-tab automation leases.
- Preserve range-based NLH analysis, exact heads-up river enumeration, custom sizing and cancellable pauses.
- Validate participant identities, stacks, bets and active status before reusing observations.
- Add English/Russian docs, MIT license, contributor/security guidance and sanitized fixtures.
- Add cross-platform CI, allowlisted ZIP builds, SHA-256 checksums and tag-triggered verified releases.

Private prototype artifacts are excluded. Strategy strength and win rate have not been benchmarked against human players or established agents.
