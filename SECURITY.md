# Security and privacy

Runtime access is limited to PokerNow HTTPS game pages and local extension storage. No backend, telemetry, cookies, browser-history or password permissions are requested.

Treat page content as untrusted. Do not evaluate page-supplied scripts, inject participant names into HTML, access hidden opponent cards or add remote executable code. Keep action guards and the cross-tab lease intact.

Report security/privacy issues through **Security → Advisories → Report a vulnerability** if enabled. Otherwise use a contact channel on the maintainer's GitHub profile. Do not post credentials/private identifiers publicly. Ordinary issues may include sanitized, synthetic reproductions.

Strategy decisions can be poor; site changes and connectivity problems can stop execution. Audited security, profitable play and approval from PokerNow are not claimed.
